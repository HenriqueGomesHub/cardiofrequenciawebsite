# Site da Cardiofrequência

Este é o site da Cardiofrequência, clínica de exames do coração, ultrassom e endoscopia em Angra dos Reis. É uma página só, onde o paciente vê os exames, entende como agendar pelo WhatsApp, conhece a clínica por fotos, lê avaliações e encontra o endereço no mapa. A página fica no `index.html`, o visual no `css/style.css`, e o telefone, a lista de exames e as avaliações ficam no começo do `js/main.js`, fáceis de mudar. As fotos estão na pasta `img` e os ícones da aba do navegador na pasta `favicon`.
